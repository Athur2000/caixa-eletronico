# 🏦 Caixa Eletrônico em Python

## 🇧🇷 Português

Um sistema simples de caixa eletrônico desenvolvido em Python como projeto de prática e aprendizado.

### ⚙️ Funcionalidades

* 💰 Consulta de saldo
* 💵 Depósitos
* 🏧 Saques
* 📄 Extrato de operações
* ✅ Validação de depósitos
* ✅ Validação de saques conforme o saldo disponível
* 🚪 Encerramento do programa

### 🧠 Conceitos praticados

* Variáveis
* Funções
* Estruturas condicionais (`if/elif/else`)
* Estrutura de repetição (`while`)
* Listas
* `input()` e conversão de tipos
* Validação de dados
* Escopo de variáveis

### 🛠️ Tecnologias

* Python 3

### ▶️ Como executar

Clone o repositório e execute o arquivo principal:

```bash
python caixa_eletronico.py
```

## 🇺🇸 English

A simple ATM system developed in Python as a practice and learning project.

### ⚙️ Features

* 💰 Balance inquiry
* 💵 Deposits
* 🏧 Withdrawals
* 📄 Transaction history
* ✅ Deposit validation
* ✅ Withdrawal validation based on available balance
* 🚪 Program exit

### 🧠 Concepts Practiced

* Variables
* Functions
* Conditional statements (`if/elif/else`)
* Loops (`while`)
* Lists
* `input()` and type conversion
* Data validation
* Variable scope

### 🛠️ Technologies

* Python 3

### ▶️ How to Run

Clone the repository and run the main file:

```bash
python caixa_eletronico.py
```
